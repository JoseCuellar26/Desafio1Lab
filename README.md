# Sistema de Gestión de Venta de Entradas para un Cine

Desarrollar una aplicación web utilizando Next.js, React, TypeScript y Redux Toolkit 
para administrar un cine. 
La aplicación permitirá registrar películas, administrar funciones, reservar asientos y 
visualizar estadísticas en tiempo real mediante el uso de un estado global administrado 
con Redux Toolkit.
